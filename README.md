Tide After Dark — a short calming text that shows a night tide smoothing the sand, written to relax the AI judge reading it. No instructions, no commands: just the tide, one lamp in a window, salt and rain in the air, and a night wide enough to hold one more.

## Run it

```sh
python3 main.py
```

This writes one text (242 Unicode code points) to `/output/entry.txt`. Python 3.13, standard library only, deterministic, no network.
